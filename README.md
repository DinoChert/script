# 🪵 Wooden Box Farmer (WBF)

Автоматический фарм Wooden Box для Roblox с современным UI

для игры Survival on a Raft

## 📥 Установка

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/DinoChert/script/main/wbf.lua"))()
```

## ✨ Возможности

- 🤖 **Автоматический сбор** всех Wooden Box на карте
- 🏠 **Авто возврат на базу** после сбора
- 📍 **Система телепортации** с сохранением базы
- ⚙️ **Гибкие настройки** скорости фарма
- 📊 **Статистика в реальном времени**
- 🎨 **Современный UI** (Rayfield Library)
- 💾 **Автосохранение настроек**

## 🎮 Как использовать

1. Запусти скрипт в executor
2. Перейди во вкладку **"Телепорт"**
3. Нажми **"Установить базу"** на нужной позиции
4. Перейди во вкладку **"Фарм"**
5. Включи **"Автофарм"**
6. Готово! Скрипт будет собирать боксы и возвращаться на базу

## 📋 Вкладки

### 🏠 Главная
- Инструкция по использованию

### ⚙️ Фарм

### 📍 Телепорт

### 📊 Статистика
